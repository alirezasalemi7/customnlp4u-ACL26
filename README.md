# CustomNLP4U @ ACL 2026 — Proceedings

Proceedings repository for the **Second Workshop on Customizable NLP**
(CustomNLP4U), co-located with ACL 2026 in San Diego, July 3, 2026.

Workshop site: https://customnlp4u.github.io/

ISBN: **979-8-89176-396-8**

## Contents
